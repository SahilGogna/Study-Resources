# Cloud Engineering Roadmap (Resource Doc)

---

## Why Cloud Engineering in Canada Right Now

- Cloud adoption in Canadian enterprises has grown faster than almost any other tech category
- Entry-level cloud engineer roles start at $70,000–$95,000 CAD
- Mid-level roles (3–5 years) average $100,000–$140,000 CAD
- Banks, retail, and telecom are migrating core infrastructure to AWS and Azure, creating steady demand
- Most roles do **not** require a CS degree, certifications and hands-on projects carry equal or more weight

---

## Step 1 — Networking and Linux Basics

- Understand TCP/IP, DNS, HTTP/HTTPS, load balancers, firewalls
- Get comfortable in a Linux terminal, file permissions, processes, shell scripting basics
- This is the foundation everything else sits on, do not skip it

### Free Resources

- NetworkChuck on YouTube — networking fundamentals
- Linux Journey — [linuxjourney.com](http://linuxjourney.com)
- KodeKloud free Linux basics course

---

## Step 2 — Pick One Cloud Provider

This is where most aspirants quit, the course list looks overwhelming. Pick one and go deep before touching the others.

- **AWS** — largest market share, most job postings in Canada
- **Azure** — dominant inside Canadian banks and enterprise (RBC, TD, Scotiabank, BMO all run Azure workloads)
- **GCP** — smaller footprint in Canada, but growing in data and AI-heavy teams

**Recommendation for Canada:** start with AWS or Azure, both have the deepest local job pools.

---

## Step 3 — Infrastructure as Code (IaC)

- Learn **Terraform** first, it is cloud-agnostic and the most requested IaC skill in Canadian job postings
- Learn your provider's native tool as a secondary skill, CloudFormation for AWS or Bicep for Azure
- Without IaC on your resume, you read as a console-clicker, not an engineer

### Free Resources

- HashiCorp Learn — official free Terraform tutorials
- KodeKloud Terraform course

---

## Step 4 — Containers and Kubernetes

- Learn Docker first, build and run your own containers
- Move to Kubernetes, understand pods, deployments, services, and basic cluster architecture
- Canadian companies like Shopify, Lightspeed, and Wealthsimple run containerized infrastructure at scale, this is a heavily screened skill

### Free Resources

- KodeKloud Docker and Kubernetes courses (free tier)
- Kubernetes official docs — [kubernetes.io/docs](http://kubernetes.io/docs)

---

## Step 5 — Get Certified

| Certification | Best For | Difficulty | Cost (CAD) |
| --- | --- | --- | --- |
| AWS Cloud Practitioner | Absolute beginners | Beginner | ~$130 |
| AWS Solutions Architect Associate | Most recognized entry cert | Intermediate | ~$220 |
| Microsoft Azure Administrator (AZ-104) | Bank and enterprise roles | Intermediate | ~$185 |
| Certified Kubernetes Administrator (CKA) | Platform/DevOps track | Advanced | ~$450 |

> **Note:** One associate-level cert (AWS SAA or AZ-104) is enough to start applying. CKA comes later, once you have hands-on Kubernetes experience.
> 

---

## Step 6 — Build Real Projects and Document Them

This is what separates you from every other candidate with the same certifications.

### Project ideas

- Deploy a 3-tier web app on AWS or Azure using Terraform, end to end
- Containerize an existing app with Docker, deploy it to a small Kubernetes cluster
- Set up a CI/CD pipeline (GitHub Actions or Azure DevOps) that auto-deploys on push
- Write up each project on GitHub with architecture diagrams and what you'd improve

## Job Search Strategy for Canada

- **LinkedIn** — filter by Canada, posted in last 7 days, cloud engineer or DevOps engineer
- **Government of Canada Job Bank** — [jobbank.gc.ca](http://jobbank.gc.ca)
- **Indeed Canada** — search cloud engineer, platform engineer, DevOps engineer

### Keywords to use in your resume

- AWS, Azure, Terraform, Kubernetes, Docker, CI/CD
- Infrastructure as Code, cloud migration, cost optimization
- AWS Solutions Architect Associate or AZ-104 (only once earned)

### Canadian resume tips

- One page if under 5 years experience
- Certifications near the top
- Quantify everything, "reduced deployment time by 40 percent" beats "worked on deployments"
- No photo, no date of birth, this is Canadian standard
